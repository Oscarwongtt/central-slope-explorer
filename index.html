How this map works

The street and terrain map use OpenStreetMap tiles. Choose A and B once, then search for walking routes. If only one is available, choose a via point on a different street to request an additional walking path connecting the SAME A and B. Saved routes do not disappear when another route is added. The public pedestrian routing service may snap endpoints or via points to nearby mapped paths.

Terrain elevations come from Open-Meteo's approximate 90 m digital elevation model. They do not measure actual road or staircase gradient. Short sections can show unreliable values; use for exploration, not access or safety decisions.

No API key or billing configuration. Public demo routing services have strict fair-use limits and are not reliable for many simultaneous students. For a full class, deploy a managed routing backend or precompute a small set of real routes. The website does not invent missing alternatives.
